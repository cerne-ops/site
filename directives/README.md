# Diretivas do projeto

Este diretório contém SOPs de operação para orquestrar o projeto sem alterar a lógica de negócio manualmente.

Diretivas atuais:
- [`run_site_local.md`](run_site_local.md): fluxo padrão para subir o site localmente com Vite.
- [`deploy_local_preview.md`](deploy_local_preview.md): validação local do build com o mesmo adaptador Node usado em produção.
- [`runtime_checklist.md`](runtime_checklist.md): checklist operacional rápido antes de iniciar alterações.
- [`deploy_vps.md`](deploy_vps.md): SOP de publicação do Site em produção via VPS/Nginx/PM2.

O mapa do estado atual, documentos vigentes e histórico de entregas está em [`docs/README.md`](../docs/README.md).
